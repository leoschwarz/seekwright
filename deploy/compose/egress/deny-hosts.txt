# The fetch role's deny-list: hosts `fetch` must not reach, however the caller phrased the URL.
# One host per line, in the spelling Squid reads: a leading dot matches that domain and every host under
# it, and a bare host matches that one host only. Blank lines and `#` lines are for the reader -- Squid
# reads deploy/compose/generated/fetch-deny.txt, the comment-free rendering of this file
# (tools/egress_lists.py).
# Add the host you want refused here, re-run `uv run python -m tools.egress_lists`, restart the fetch proxy.
#
# A deny-list is a policy, not a defence: any host not named here stays reachable, and a caller that
# controls a name outside this list can carry bytes out through it. What it does stop, cheaply and at the
# network layer, is the two shapes an injected prompt reaches for: a callback check that confirms a
# request left this network, and a public sink to deposit what it exfiltrated.
